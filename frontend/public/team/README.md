# Team Member Avatars Directory

You can place your team member photos (JPG, PNG, WebP) directly in this folder:
`/Users/divyshresthvishwakarma/Downloads/Sih22/frontend/public/team/`

### Examples:
- `frontend/public/team/aman.jpg` -> Photo path: `/team/aman.jpg`
- `frontend/public/team/divyshresth.jpg` -> Photo path: `/team/divyshresth.jpg`

You can also:
1. Directly click **"Upload Image"** in the **Edit Member** modal on the website to select any photo from your Mac.
2. Or paste any online URL (such as GitHub profile avatars `https://github.com/<username>.png`).
